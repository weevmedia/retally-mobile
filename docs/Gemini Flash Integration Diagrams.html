Recommended integration

A guarded fallback, not a rewrite.

Keep the fast, free scanner path. Send only torn or low-confidence receipts to Gemini Flash through a protected Firebase function, then let the person correct the result before saving.

What makes this “moderate”

  • Already built: capture, crop, OCR, parser, review UI and Firebase foundation.
  • New work: confidence policy, temporary upload, callable function, Gemini request and JSON validation.
  • Hardest part: deciding when AI helps and how to merge two imperfect answers without hiding uncertainty.
  • Non-negotiable: API key stays server-side; auth, App Check, rate limits and deletion policy are enforced.

Practical delivery plan

2–4 days

Proof of concept

One callable function, strict JSON, manual “Improve scan” button and review-screen result.

3–5 days

Automatic fallback

Confidence rules, field merge, total reconciliation, retry and user-friendly failure states.

2–3 days

Production guardrails

App Check, quotas, logging without receipt text, image retention rules and device tests.

✓

Recommendation

Start with a manual “Improve scan” fallback on the review screen. Once real scans show reliable gains, add automatic escalation for low-confidence receipts. This limits cost, risk and scope while proving the feature with actual torn receipts.
